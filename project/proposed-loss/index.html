Proposed loss

A new loss function for training neural-network classifiers, measured against the losses in use today. The loss itself stays private until the paper is published, so this page covers how it is being tested rather than what it is.

Overview

  • 4established losses it is measured against
  • 0machine-learning libraries: the network, the training loop and every loss are plain C++
  • 60/20/20train, validation and test split, repeated over several seeds

Cross-entropy is the default loss for classification, and most alternatives are judged on images or text. This work asks whether a different loss trains better classifiers on ordinary tabular data, the kind most real systems still run on.

Every comparison runs on the same small network, written from scratch, so that a difference in the result can only come from the loss.

Results are held back until the paper is out.

Method

  1. A library from scratch

    Dense layers, sigmoid hidden units, a softmax output and gradient-descent training, written in C++ so every operation is visible and identical for each loss.

  2. Strong baselines

    Cross-entropy, Focal (γ = 2), PolyLoss (ε = 2) and GCE (q = 0.7), each at a fixed, standard setting.

  3. Tabular benchmarks

    Public datasets that differ in size, number of classes, imbalance and noise.

  4. A fair comparison

    The same network, budget and splits for every loss; the proposed loss’s settings are chosen on the validation split only, and results are averaged over seeds and checked with statistical tests.
