I'm Erdi. I study Computer Science at Universitas Gadjah Mada, and most of my projects sit where models meet machines: how a loss function shapes training, how much memory an LLM needs while it generates, and how much faster a pipeline runs once it moves to a GPU.

I write C++ when I want to see every operation, Python when I need to test an idea quickly, and Dart when an idea has to become an app people can hold. I'm working toward a role as an AI engineer or systems engineer.
